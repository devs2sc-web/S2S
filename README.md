# โครงการ "SEED TO SUCCESS เมล็ดพันธุ์สู่ความสำเร็จ"
## มหาวิทยาลัยธรรมศาสตร์ (Thammasat University)

ระบบลงทะเบียนสัมมนาผู้ใช้งาน (Part 1) และระบบคลังสื่อการเรียนรู้ออนไลน์พร้อมจัดการสิทธิ์ (Part 2) พัฒนาขึ้นเพื่อรองรับผู้เข้าร่วมงานสัมมนา On-site ~1,000 คน และคัดกรองผู้มีสิทธิ์เข้าศึกษาต่อในสื่อออนไลน์และกิจกรรมของโครงการ

---

## 🌟 ฟังก์ชันการทำงานหลัก (System Overview)

### 📌 PART 1: การลงทะเบียนในงานสัมมนา (On-site Event Registration)
* **รองรับผู้เข้าร่วมงานประมาณ 1,000 คนพร้อมกัน:**
  * ฐานข้อมูล SQLite ปรับแต่งด้วยโหมด **WAL (Write-Ahead Logging)** และ Concurrency Cache ป้องกันปัญหาคอขวดเมื่อสแกนพร้อมกันในห้องประชุม
* **เปิดผ่าน LINE Official Account (LINE LIFF) หรือ Web Browser:**
  * ดึง LINE User ID, ชื่อ และรูปโปรไฟล์อัตโนมัติ
  * ฟอร์มกระชับ: ชื่อ-นามสกุล, เบอร์โทรศัพท์, อีเมล, สถาบัน/สถานะ (นักศึกษา มธ. / ต่างสถาบัน / บุคคลทั่วไป / Start-up) และรหัสนักศึกษา
  * มีช่องแสดงความจำนง: **"สนใจเข้าร่วมคอร์สเรียนรู้ออนไลน์และกิจกรรม Part 2"**
* **ผลลัพธ์หลังลงทะเบียน:**
  * ได้รับ **Digital Pass / E-Ticket** พร้อมรหัสสมาชิก (`SEED-2026-xxxxx`) และ QR Code สำหรับแสดงแก่เจ้าหน้าที่หน้างาน
  * มีปุ่มทางลัดไปยัง **"ระบบเรียนรู้ออนไลน์ (Part 2)"** ทันที

---

### 📌 PART 2: คลังสื่อการเรียนรู้ออนไลน์ (Learning Portal)
* เข้าใช้งานผ่านเมนู: [http://127.0.0.1:5000/portal](http://127.0.0.1:5000/portal)
* **ระบบเข้าสู่ระบบแบบ Dual-Login (LINE & Email/Phone):**
  * บนสมาร์ทโฟน: ล็อกอินผ่าน LINE ได้ทันที
  * บนคอมพิวเตอร์ / โน้ตบุ๊ก: ล็อกอินด้วย **อีเมล** หรือ **เบอร์โทรศัพท์** ที่ใช้ลงทะเบียนในงานสัมมนา
* **ระบบตรวจสอบสิทธิ์อัตโนมัติ (Access Gatekeeper):**
  * **กรณีที่ยังไม่อนุมัติ (Pending Review):** ระบบจะแสดงหน้า *"ใบสมัครของคุณอยู่ระหว่างการพิจารณาตรวจสอบสิทธิ์จากทีมงานโครงการ SEED TO SUCCESS"* พร้อมแจ้งรายละเอียดสมาชิกและคำแนะนำ
  * **กรณีที่ได้รับการอนุมัติแล้ว (Approved):** ปลดล็อกหน้า **Learning Dashboard** ทันที
* **เนื้อหาในคลังสื่อการเรียนรู้:**
  * วิดีโอบรรยาย (YouTube Embed / Vimeo)
  * เอกสารประกอบการเรียนรู้ (PDF / Slide ดาวน์โหลด)
  * กิจกรรม Workshop / Challenge ส่งข้อเสนอโครงการ
  * ฟิลเตอร์แยกตามหมวดหมู่บทเรียน

### 📌 ADMIN BACKOFFICE: การจัดการสิทธิ์และสื่อการเรียนรู้
* เข้าใช้งานผ่าน: [http://127.0.0.1:5000/admin](http://127.0.0.1:5000/admin) *(User: `admin` | Pass: `admin1234`)*
* **เมนู 1: รายชื่อ & จัดการสิทธิ์ Part 2 (Members & Access Control):**
  * ดูสถิติ: ลงทะเบียนทั้งหมด, รออนุมัติสิทธิ์, อนุมัติสิทธิ์แล้ว, สมัครวันนี้
  * ฟิลเตอร์กรองรายชื่อ: ทั้งหมด / รอการอนุมัติ / อนุมัติสิทธิ์แล้ว / เฉพาะร่วมสัมมนา
  * **ปุ่มกดอนุมัติสิทธิ์รายบุคคล (1-Click Approve / Revoke)**
  * **ปุ่ม "อนุมัติสิทธิ์ผู้ที่รอทั้งหมด" (Bulk Approve All Pending)** อนุมัติทุกคนที่รออยู่ได้ในคลิกเดียว
  * **ส่งออกข้อมูลเป็นไฟล์ Excel / CSV:** มีคอลัมน์สถานะสิทธิ์, วันเวลาที่อนุมัติ, และผู้อนุมัติ รองรับภาษาไทย 100%
* **เมนู 2: คลังสื่อการเรียนรู้ (Learning Materials Manager):**
  * แอดมินสามารถเพิ่ม ลบ หรือแก้ไข วิดีโอบรรยาย เอกสารดาวน์โหลด หรือลิงก์กิจกรรมใหม่ๆ ได้ตลอดเวลา
* **เมนู 3 & 4: ปรับแต่งหน้าตา & จัดการฟิลด์:**
  * ปรับแต่งชื่อโครงการ โลโก้ ข้อความต้อนรับ สีหลัก และเปิด/ปิดฟิลด์ในแบบฟอร์มได้อิสระ

## 🚀 วิธีการเปิดใช้งานระบบ

ดับเบิลคลิกไฟล์ `run.bat` หรือพิมพ์คำสั่งใน Terminal:
```bash
python app.py
```

เมื่อระบบเริ่มทำงาน:
1. **หน้าลงทะเบียนสัมมนา (Part 1):** [http://127.0.0.1:5000](http://127.0.0.1:5000)
2. **หน้าคลังสื่อการเรียนรู้ออนไลน์ (Part 2):** [http://127.0.0.1:5000/portal](http://127.0.0.1:5000/portal)
3. **ระบบหลังบ้านผู้ดูแลระบบ (Admin):** [http://127.0.0.1:5000/admin](http://127.0.0.1:5000/admin)

---

## 📲 วิธีนำไปผูกกับ LINE Official Account (Rich Menu)
1. นำ URL เว็บไซต์ไประบุใน **LINE Developers Console** เพื่อสร้าง **LIFF ID**
2. ใส่ `LIFF_ID` ลงในไฟล์ `.env`
3. ใน **LINE Official Account Manager**:
   * ปุ่มที่ 1 ในริชเมนู: **"ลงทะเบียนร่วมงาน"** -> ใส่ LIFF URL หน้าลงทะเบียน (`https://liff.line.me/{LIFF_ID}`)
   * ปุ่มที่ 2 ในริชเมนู: **"คลังสื่อการเรียนรู้"** -> ใส่ LIFF URL ของหน้า Portal (`https://liff.line.me/{LIFF_ID}/portal`)
